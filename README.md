# 💻 Sistema de Cadastro de Equipamentos

Projeto desenvolvido em linguagem C como parte da minha jornada de aprendizado em Análise e Desenvolvimento de Sistemas (ADS).

## 📌 Sobre o projeto

O sistema permite cadastrar equipamentos, informar seus estados e consultar os equipamentos registrados durante a execução do programa.

## ⚙️ Funcionalidades

- Cadastrar equipamentos.
- Informar o nome e o estado de cada equipamento.
- Listar os equipamentos cadastrados.
- Encerrar o programa pelo menu.

## 🛠️ Tecnologias utilizadas

- Linguagem C
- Biblioteca `stdio.h`
- Biblioteca `string.h`

## 🎯 Objetivo

Praticar lógica de programação, vetores, estruturas de repetição, estruturas condicionais e manipulação de textos.
